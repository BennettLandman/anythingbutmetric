THERE IS ACTUAL MATH IN HERE

Ridiculous units.
Reasonable arithmetic.

Pick a measurement. We divide it by a reference object of the same kind, then choose three comparisons. Each batch includes a scale match when one is available: between one tenth and ten of a reference object. Shuffle for a new batch. The sign follows your favorite.

Object sizes are approximate. Each selection shows its reference value and assumptions. Force uses weight under standard gravity; pressure compares magnitudes, with gauge and absolute references labeled. Temperature ratios use absolute kelvin values. Moles count specified entities; candela references state a viewing direction or beam model. Liters are included as an SI-compatible convenience.

These are novelty comparisons and signs. The number on a sign is rounded; the underlying conversion uses the full reference value.
